# llms-website-gen-test
GPT-6, Claude 5.5, Gemini 4 Argon, DeepSeek V4.1, Qwen 3.8 и GLM 5.3 website generating test

## Prompt

```
Ты — фронтенд-разработчик. Сгенерируй один файл index.html для одностраничного сайта компании ООО «Рога и Копыта», Черноморское отделение Арбатовской конторы по заготовке рогов и копыт.

Верни только код файла, без пояснений, без разбивки на несколько сообщений и без markdown-обёртки. Весь CSS — внутри <style>, весь JavaScript — внутри <script>. Файл должен открываться в браузере двойным кликом и работать без правок.

Содержание сайта:
1. Шапка с логотипом-текстом «Рога и Копыта» и навигацией по якорям: «О нас», «Преимущества», «Отзывы», «FAQ», «Контакты». На мобильных навигация сворачивается в кнопку-бургер.
2. Секция «О нас»: краткое описание отделения, годы работы, направления деятельности — заготовка рогов, приём копыт, оптовая поставка, работа с юридическими лицами. Текст осмысленный, без lorem ipsum.
3. Секция «Преимущества»: четыре-шесть карточек с иконками (можно символами или инлайн-SVG) и коротким описанием. Например: приёмка 24/7, собственный парк транспорта, прозрачные акты приёмки, работа с НДС, выезд оценщика.
4. Секция «Отзывы»: два-три отзыва от вымышленных контрагентов с именем, должностью и городом.
5. Секция «FAQ»: минимум пять вопросов с раскрывающимися ответами. Аккордеон интерактивный, с aria-expanded.
6. Секция «Контакты»: форма обратной связи с полями имени, email и сообщения. Кнопка «Отправить». Данные никуда не уходят, отправка имитируется.
7. Подвал с копирайтом и юридическим адресом.

Обязательные элементы:
— Переключатель светлой и тёмной темы в шапке. Реализуется через CSS-переменные и переключение класса на <html> или <body>. Выбор сохраняется в localStorage и применяется при повторном открытии файла.
— Модальное окно (попап) с условиями приёмки рогов и копыт. Открывается по кнопке «Условия приёмки» в секции «О нас» или в подвале. Закрывается по крестику, по клику на оверлей и по клавише Escape. Фокус при открытии переводится в попап.
— Плавный скролл к якорям при клике по пунктам навигации. Реализация — через CSS scroll-behavior или через JavaScript, на твой выбор.
— Клиентская валидация формы: пустые поля и некорректный email блокируют отправку. Сообщение об ошибке выводится рядом с соответствующим полем, не через alert и не ломая вёрстку. При успешной отправке показывается сообщение об успехе и форма очищается.
— Анимации и гладкие переходы.

Технические ограничения:
— Семантическая разметка HTML5: header, nav, main, section, footer, form, label, fieldset, button. Не оборачивай всё в div без необходимости.
— Соблюдай БЭМ: блок__элемент--модификатор. Классы должны быть осмысленными и последовательными.
— Вёрстка mobile-first, с явным <meta name="viewport" content="width=device-width, initial-scale=1"> и минимум двумя контрольными точками (например, 768px и 1200px). Проверь, что на ширине 360px нет горизонтальной прокрутки.
— Доступность: alt у изображений и SVG, видимый фокус на интерактивных элементах, контраст текста и фона не ниже AA, label связан с полем через for/id.
— CSS пиши самостоятельно, без Bootstrap, Tailwind и других фреймворков. Разрешено подключить Normalize.css и шрифты с Google Fonts, но вёрстка должна сохранять читаемость и без них.
— JavaScript — ванильный, без jQuery, React и других библиотек. Никаких внешних запросов, кроме разрешённых шрифта и Normalize.css.
— Весь код в одном файле. Не оставляй комментариев вида «здесь добавьте свой код» и не сокращай секции многоточиями.

Дизайн: сдержанный деловой стиль, уместный для компании, которая всерьёз занимается заготовкой рогов и копыт. Цветовая схема нейтральная, акцентный цвет один. Типографика читаемая, отступы последовательные. Не делай сайт похожим на типовой шаблон с градиентными кнопками и стоковыми иллюстрациями.
```
